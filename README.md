# Anime Tap Clicker 🎮

Атмосферный кликер с коллекцией аниме-персонажей. Зарабатывай монеты, открывай новых горничных, читай их фэнтезийные истории и проходи этапы!

![Скриншот игры](assets/screenshots/icon.png) *(если есть скриншот, добавь его сюда)*

## 🚀 Установка и запуск

1. Скачайте проект или склонируйте репозиторий.
2. Откройте файл `index.html` в любом браузере (Chrome, Safari, Firefox).
3. **Важно:** Если вы используете VS Code, лучше установить расширение **Live Server** и открыть проект через него (правой кнопкой мыши по `index.html` -> "Open with Live Server"). Это позволит корректно загружать изображения из папки `assets`.

## 🎮 Как играть

* **Тап (TAP):** Нажимайте на центральную кнопку, чтобы зарабатывать монеты.
* **Улучшения:** Тратьте монеты на повышение силы клика (DPC) и покупку автокликеров.
* **Персонажи:** По мере накопления монет открываются новые героини (от ранга D до SSS). У каждой есть уникальная история, которую можно прочитать в меню «Characters».
* **Смена персонажей (REROLL):** Кнопка бесплатна и позволяет быстро переключаться между уже открытыми героинями.
* **Магазин (SHOP):** Улучшайте глобальные характеристики.
* **Статистика (STATS):** Смотрите свой прогресс и топ игроков.
* **Этапы:**
    * **1 Этап (D - S):** Доступен сразу.
    * **2 Этап (SS - SSS):** Открывается через 1 час после прохождения 1 этапа. 
    * **Финал:** Откройте последнего персонажа «Спасибо!», чтобы увидеть благодарность и контакты для предложений.
